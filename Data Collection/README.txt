# Indian E-commerce Sales Dataset (Synthetic)

This is a realistic synthetic dataset created for testing the BizInsight AI dashboard.
It does not represent real customers or real transactions.

- Rows: 6,500 order-line records
- Period: 2024-01-01 to 2025-12-31
- Currency: INR
- Country: India
- Products: 20
- Customers: 1,250 possible customer IDs

Suggested analyses:
- Revenue, cost, profit and profit margin
- Orders, units sold and average order value
- Monthly revenue trends
- Product/category/subcategory performance
- Customer purchase frequency
- City/state performance
- Payment method and sales channel mix
- Order status and shipping time analysis

Important:
- Cancelled and returned records are marked in Order_Status.
- The Total_Revenue_INR / Total_Cost_INR / Profit_INR columns are line-level values.
- Order_ID repeats only if an order has multiple line items? In this generated file each row has its own order ID to make order counting straightforward.
- All names and IDs are synthetic.
